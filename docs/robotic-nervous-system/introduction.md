This module introduces the Robot Operating System (ROS 2), the middleware that acts as the nervous system for modern robots. 

We will cover the following topics:
-   **Introduction to ROS 2:** What is a middleware and why is it essential for robotics?
-   **ROS 2 Fundamentals:** Hands-on practice with Nodes, Topics, and Services using Python.
-   **Python Agents with rclpy:** How to connect high-level agent logic to the ROS 2 ecosystem.
-   **URDF for Humanoids:** How to describe the physical structure of a robot for simulation and control.

By the end of this module, you will be able to build simple, multi-part robotics applications and understand the fundamental architecture of a ROS 2-powered system.
